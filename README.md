# Figure Scape · 梦境

**把自己的角色带进 Coo 的日常。**

梦境支持导入 Live2D 模型、兼容的 Coo 形象包和 Spriter 源工程，在网页编辑台调整装扮、动作和触碰反应。角色可以留在桌面、走进房间，或在竖屏和动态壁纸上继续同一段对话。小屋世界可从引擎页按需安装，Android 上的 Figure Pet 可通过局域网接续梦境的对话和装扮。梦境对话面板可以接续原版桌宠历史。

## 安装与启动

1. 在 Coo 的扩展市场搜索并安装 `cortico-world-figure-scape`，按界面提示启用或重启。
2. 打开「Figure Scape · 梦境 → 工作台」，点击「启动桌宠」。新安装默认选中内置角色《Coo · 重刀断岳》1.4.2，可以直接试用它的装扮、下劈特效和音效。
3. 要换成自己的角色，拖入模型文件夹或 ZIP，也可以用导入按钮选择文件夹或 `.model3.json`。兼容的 Coo 形象包走同一个入口。导入后，在角色卡上点「使用」。

梦境使用 Cortico World API 6，在 Windows x64 上使用 Coopanion 0.2.21 验收。原版桌宠由 Coo 托盘管理，梦境由自己的工作台管理。

在「外观」页预览并应用暖玫瑰、Coo 经典、雾蓝或琥珀。每套都提供浅色和深色预览，配色会应用到梦境面板、网页编辑台、桌宠气泡和场景控件。

## 连接 Figure Pet

1. 在梦境工作台导入区旁的 **Figure Pet** 卡片点「下载 APK」，把签名安装包传到 Android 10 或更新版本的手机。从 Git 源码安装时，可将单独构建的 Figure Pet 1.0.0 签名 APK 放入 `src/phone-link/client/figure-pet-1.0.0.apk`，工作台会提供下载。
2. 点「连接手机 → 启用手机连接 → 生成配对码」。让手机和电脑连同一个局域网，在手机 App 的「设置 → 连接 Coo」扫码。配对码五分钟内有效，可使用一次。
3. 在手机 App 的「设置 → 连接 Coo → 电脑装扮来源」选择 **Figure Scape · 梦境**（旧版 APK 默认选择原版桌宠，需要手动切换一次）。手机端只连接梦境。开启「跟随电脑角色和装扮」即可同步，也可从梦境的角色库选一套保存到手机。

如果 Coo 控制台用了非默认端口或启用了访问密码，在启用连接前打开「连接手机 → 控制台连接设置」，填写电脑本机的控制台端口和密码。密码由当前部署的 World 密钥存储保管，不会写入普通配置或发送给手机。

从独立 Figure Pet 扩展迁移时，先在同一个 Coo 部署停用旧的 Figure Pet World，再从梦境工作台启用手机连接。已有手机会沿用原配对记录和服务身份。可以在「管理连接」中解除配对或停用局域网连接。更新后，如果工作台仍停在旧页面，重新打开 Coo 的工作台以加载新版资源。

## 编辑自己的角色

从角色卡点「编辑角色」，在浏览器查看角色并调整取景、动作与表情、装扮和触碰。桌宠关闭时也能编辑，草稿按角色保存。

- **原始 Live2D**（`.model3.json`）可以试播模型自带的动作与表情，并按模型支持的能力配置裁切、移动、注视和口型。
- **Coo 形象包**（`figure.json`，Body API 2）从作者的配置和渲染入口起步。可以调整开放的装扮和动作，为角色新增触碰规则，或恢复作者默认。
- **Spriter 工程**（`.scml` 和工程内的 PNG）可拖入文件夹或 ZIP。单角色工程会导入为形象包，保留分层动画、原版外观与作者装扮映射，并可把原生动作绑到触碰。素材需使用有权导入的版本。目前支持源工程，编译后的 `anim.zip` 尚未接入。
- **触碰工作区**可以调整默认区域或画出自定义范围，给戳和抚摸指定不同的动作与表情，并选择何时向 Coo 上报。画范围时角色会定住，方便描边和试触。

[两个角色格式的渲染方式](docs/architecture.md#角色渲染)

## 把角色带到不同场景

| 场景 | 角色和对话如何呈现 |
| --- | --- |
| 桌面 | 角色在屏幕工作区活动，发言用随身气泡。 |
| 小屋 | 角色能走到家具旁坐下或休息，输入框和即时气泡靠近窗口下沿。 |
| 竖屏 | 9:16 的视频通话式画面，用实时角色作背景，消息以左右气泡显示。 |
| 壁纸 | 用本机图片、视频或兼容的 Wallpaper Engine 项目做背景，发言显示为字幕。 |
| 小屋世界 | 按需下载 Cabin World，成为像素地图里的住户，串门、购物或去电玩城。 |

在工作台的「场景」或桌宠的右键操作台中，点场景卡查看设置，再点「进入场景」。桌面、小屋、竖屏和壁纸各自记住角色大小与位置。小屋、竖屏和壁纸提供输入框和麦克风。

在「壁纸 → 壁纸库」添加本机背景，或查找 Steam 已下载的壁纸。更换背景后可继续留在库里浏览。壁纸音量独立于角色声音，「角色构图」按壁纸保存站位和接地线。抓起角色再松手，角色会落到这条线上。实时壁纸由 WebWallGL 绘制，无法加载时可使用项目自带的视频或封面。

「操作台布局」用于配置右键应用入口、靠近按钮和操作台尺寸。在「引擎 → 桌宠窗口」可安装窗口组件。「高级启动设置」可选择自定义程序、调整端口、在浏览器中预览桌宠或恢复鼠标操作。

### 小屋世界 Cabin World

Windows x64 用户可在「引擎 → 小屋世界」下载并安装梦境适配的 Cabin World 1.1，或选择本机已有安装。组件从 Figure Scape 的 GitHub Releases 单独下载。装好后点「进入小屋世界」，也可以从场景页或桌宠右键进入。升级扩展时直接复用兼容的安装和原存档。 [Figure Scape 组件发布页](https://github.com/as124da1231/cortico-world-figure-scape/releases)

当前 Live2D 或 Coo 形象包角色以实时画面参与地图的移动和遮挡。游戏窗口右侧的「对话」直接读写当前 Coo 会话。Coo 可以查看附近家具、走去目的地、购物、进餐和游玩。进行中的活动按任务编号查询游戏回执。从梦境工作台的「更多导入方式 → 从小屋世界导入」可以把随附的像素住户导入模型库。

在游戏的住户面板可以修改名字、房屋名称和房间分配。电玩城的历史对局可从「玩法与战绩」查看。 [Cabin World by VADS](https://github.com/BabyBus2022/cabin-world/releases/tag/V1.1.0)

## 对话、声音与直播

梦境在自己的窗口里使用 Coo 的会话。竖屏读取原版桌宠的文字、语音转写和发言事件，切换身体后可以继续读对话。梦境的回复先写入会话，有可用窗口时再播出气泡、声音和动作。Coo 0.2.23 的原版「对话」只显示原版桌宠记录，梦境回复可在梦境的对话面板查看。

- 气泡、动作、语音与口型跟随同一次发言的播放进度，声音暂不可用时仍显示文字。
- 语音输入关闭时，点角色旁的麦克风可开启并开始收音，再点一次可结束并发送。之后按设定使用按住说话、点按录音或自动检测。取消、隐藏或关闭窗口会释放收音。
- 「声音 → 输入设置」集中显示麦克风、电平、检测门槛和试录结果。试录文字只留在设置里。同款本地识别模型可复用 Coo 原版已下载的文件。启用自动检测后，窗口可用时麦克风会持续监听。选择在线转写时，待识别的录音片段会发给你配置的服务。本地识别和在线转写可分别选择。
- 使用本机 GPT-SoVITS 时，在 GSV 开启本机语音接口并留空令牌，再到「模型服务 → 添加提供商」选择「本机 GPT-SoVITS 插件」。默认地址为 `http://127.0.0.1:9880`。试听后可设为当前语音合成模型，并到「声音 → 说话声设置」启用。音色留空时使用 GSV 当前音色，默认语速为 1×。
- 在「显示 → 全屏与直播」开启「OBS 画面」，复制浏览器源地址可单独采集桌宠画面。「截图和录屏时隐藏桌宠」默认关闭。开启后可查看 Windows 的应用状态，NVIDIA 即时重放的桌面捕获可能无法启动。同页可关闭「允许覆盖任务栏」。

## 引擎管理

从「引擎 → Live2D」查看组件状态、Core 和 SDK 许可。梦境优先校验并复用 Figure 一键安装留下的本机组件。首次下载时，梦境在确认许可后从官方来源获取 Core 和 Web Framework 源码，并在本机构建和校验 Framework。 [Live2D 官方下载页](https://www.live2d.com/en/sdk/download/web/)

「引擎」页也可安装小屋世界、管理安装来源和查看 Spriter 支持的角色格式。

## 开发

使用 Node.js 22 及以上版本和仓库指定的 pnpm 版本。将目标宿主对应的 Cortico 源码放在 `.cortico`，或在该路径建立目录联接。类型检查和集成测试会从那里读取宿主契约。

小屋组件通过 `python scripts/prepare-cabin-runtime.py --archive <输出目录>` 从已准备的运行目录生成。更新组件时，先校验并发布固定的 GitHub Release 附件，再更新主包的组件清单。公开下载与安装通过后，发布 npm 主包。

```powershell
pnpm install --frozen-lockfile
pnpm build
pnpm typecheck
pnpm test
```

通过 Coo 扩展页安装本地目录并重启 Core。面板、网页编辑台和壁纸渲染使用带内容摘要的构建资源。可在场景页验证 Cabin World 下载，或按发布检查准备本地运行包。桌宠窗口支持指定 Electron 或使用本机托管运行时。
