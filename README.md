# Figure Scape · 梦境

**把自己的角色带进 Coo 的日常。**

梦境是 Coopanion 的 Windows 角色与场景扩展。导入 Live2D 模型或兼容的 Coo 形象包，在桌面和角色聊天。在网页编辑台配置装扮、动作与触碰反应，再把角色带进小屋、竖屏、壁纸或内置的小屋世界。Android 上的 Figure Pet 可以通过局域网继续这段对话，并跟随电脑的角色与装扮。

## 安装与启动

1. 在 Coo 的扩展市场搜索并安装 `cortico-world-figure-scape`，按界面提示启用或重启。
2. 打开「Figure Scape · 梦境 → 工作台」，点击右上角「启动梦境」。新安装默认选中内置角色《Coo · 重刀断岳》1.4.2，可以直接试用它的装扮、下劈特效和音效。
3. 要换成自己的角色，拖入模型文件夹或 ZIP，也可以用导入按钮选择文件夹或 `.model3.json`。兼容的 Coo 形象包走同一个入口。导入后，在角色卡上点「使用」。

梦境使用 Cortico World API 6，在 Windows x64 上使用 Coopanion 0.2.21 验收。原版桌宠由 Coo 托盘管理，梦境由自己的工作台管理。

## 连接 Figure Pet

1. 在梦境工作台导入区旁的 **Figure Pet** 卡片点「下载 APK」，把签名安装包传到 Android 10 或更新版本的手机。从 Git 源码安装时，可将单独构建的 Figure Pet 1.0.0 签名 APK 放入 `src/phone-link/client/figure-pet-1.0.0.apk`，工作台会提供下载。
2. 点「连接手机 → 启用手机连接 → 生成配对码」。让手机和电脑连同一个局域网，在手机 App 的「设置 → 连接 Coo」扫码。配对码五分钟内有效，可使用一次。
3. 在手机里选择梦境或原版桌宠。开启「跟随电脑角色和装扮」后，手机会同步所选来源的角色。也可以从电脑角色库选一套保存到手机。

从独立 Figure Pet 扩展迁移时，先在同一个 Coo 部署停用旧的 Figure Pet World，再从梦境工作台启用手机连接。已有手机会沿用原配对记录和服务身份。可以在「管理连接」中解除配对或停用局域网连接。更新后，如果工作台仍停在旧页面，重新打开 Coo 的工作台以加载新版资源。

## 编辑自己的角色

从角色卡点「编辑角色」，在浏览器查看角色并调整取景、动作与表情、装扮和触碰。桌宠关闭时也能编辑，草稿按角色保存。

- **原始 Live2D**（`.model3.json`）可以试播模型自带的动作与表情，并按模型支持的能力配置裁切、移动、注视和口型。
- **Coo 形象包**（`figure.json`，Body API 2）从作者的配置和渲染入口起步。可以调整开放的装扮和动作，为角色新增触碰规则，或恢复作者默认。
- **触碰工作区**可以调整默认区域或画出自定义范围，给戳和抚摸指定不同的动作与表情，并选择何时向 Coo 上报。画范围时角色会定住，方便描边和试触。

[两个角色格式的渲染方式](docs/architecture.md#角色渲染)

## 把角色带到不同场景

| 场景 | 角色和对话如何呈现 |
| --- | --- |
| 桌面 | 角色在屏幕工作区活动，发言用随身气泡。 |
| 小屋 | 角色能走到家具旁坐下或休息，输入框和即时气泡靠近窗口下沿。 |
| 竖屏 | 9:16 的视频通话式画面，用实时角色作背景，消息以左右气泡显示。 |
| 壁纸 | 用本机图片、视频或兼容的 Wallpaper Engine 项目做背景，发言显示为字幕。 |
| 小屋世界 | 进入内置的 Cabin World，成为像素地图里的住户，串门、购物或去电玩城。 |

在工作台的「场景」或桌宠的右键操作台中，点场景卡查看设置，再点「进入场景」。桌面、小屋、竖屏和壁纸各自记住角色大小与位置。小屋、竖屏和壁纸提供输入框和麦克风。

在「壁纸 → 壁纸库」添加本机背景，或查找 Steam 已下载的壁纸。更换背景后可继续留在库里浏览。壁纸音量独立于角色声音，「角色构图」按壁纸保存站位和接地线。抓起角色再松手，角色会落到这条线上。实时壁纸由 WebWallGL 绘制，无法加载时可使用项目自带的视频或封面。

「操作台布局」用于配置右键应用入口、靠近按钮和操作台尺寸。点击工作台右上角的版本号，可查看运行详情、窗口启动设置和组件许可。

### 小屋世界 Cabin World

Windows x64 安装包自带 Cabin World 1.1。从「场景 → 小屋世界 → 进入小屋世界」打开游戏，首次启动使用梦境专属的新存档。

当前 Live2D 或 Coo 形象包角色以实时画面参与地图的移动和遮挡。游戏窗口右侧的「对话」直接读写当前 Coo 会话。Coo 可以查看附近家具、走去目的地、购物、进餐和游玩。进行中的活动按任务编号查询游戏回执。从梦境工作台的「更多导入方式 → 从小屋世界导入」可以把随附的像素住户导入模型库。

在游戏的住户面板可以修改名字、房屋名称和房间分配。电玩城的历史对局可从「玩法与战绩」查看。 [Cabin World by VADS](https://github.com/BabyBus2022/cabin-world/releases/tag/V1.1.0)

## 对话、声音与直播

梦境在自己的窗口里使用 Coo 的会话。竖屏读取原版桌宠的文字、语音转写和发言事件，切换身体后可以继续读对话。梦境的回复先写入会话，有可用窗口时再播出气泡、声音和动作。原版对话页能显示哪些梦境消息，取决于它是否支持读取梦境的事件。

- 气泡、动作、语音与口型跟随同一次发言的播放进度，声音暂不可用时仍显示文字。
- 在梦境的麦克风按钮上按住说话，松开发送。取消、隐藏或关闭窗口会释放收音。「声音」管理音效、说话声和语音输入。「模型服务」管理语音合成、动作编排和在线转写。电脑操作与全局快捷键由原版桌宠管理。
- 使用本机 GPT-SoVITS 时，在 GSV 开启本机语音接口并留空令牌，再到「模型服务 → 添加提供商」选择「本机 GPT-SoVITS 插件」。默认地址为 `http://127.0.0.1:9880`。试听后可设为当前语音合成模型，并到「声音 → 说话声设置」启用。音色留空时使用 GSV 当前音色，默认语速为 1×。
- 在「显示 → 全屏与直播」开启「OBS 画面」，复制浏览器源地址可单独输出梦境。「截图和录屏时隐藏 Live2D」默认关闭。开启后可查看 Windows 的应用状态，NVIDIA 即时重放的桌面捕获可能无法启动。同页可关闭「允许覆盖任务栏」。

## Live2D 运行组件

从「版本号 → Live2D 组件与许可」查看 Core 和 SDK 许可。梦境优先校验并复用 Figure 一键安装留下的本机组件。首次下载时，梦境在确认许可后从官方来源获取 Core 和 Web Framework 源码，并在本机构建和校验 Framework。 [Live2D 官方下载页](https://www.live2d.com/en/sdk/download/web/)

## 开发

使用 Node.js 22 及以上版本和仓库指定的 pnpm 版本。将目标宿主对应的 Cortico 源码放在 `.cortico`，或在该路径建立目录联接。类型检查和集成测试会从那里读取宿主契约。

```powershell
pnpm install --frozen-lockfile
pnpm build
pnpm typecheck
pnpm test
```

通过 Coo 扩展页安装本地目录并重启 Core。面板、网页编辑台和壁纸渲染使用带内容摘要的构建资源。需要验证内置小屋世界时，先按发布检查准备 Cabin World 运行包。桌宠窗口支持指定 Electron 或使用本机托管运行时。
