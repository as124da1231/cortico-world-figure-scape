# Figure Scape · 梦境

把原始 Live2D 模型和兼容 Coo 形象包带到桌面、小屋、竖屏和壁纸场景。工作台可以直接选择模型文件夹，也支持 `.model3.json`、ZIP、拖入和粘贴。取景、动作绑定、装扮和口型设置按模型保存。

## 在 Coo 中使用

梦境是 Windows 上的 Coo World 扩展，使用 World API 6。本轮在 Coopanion 0.2.21 上验收。

1. 安装并启用 `cortico-world-figure-scape`，在「Figure Scape · 梦境 → 工作台」导入模型。
2. 点击「启动梦境」。每个身体有自己的窗口，Coo 原版桌宠继续使用它的托盘和设置。
3. 从 Live2D 的气泡、竖屏输入框或麦克风与 Coo 对话。竖屏读取同一会话中的原版和 Live2D 文字消息。Live2D 发言先写入对话，活动窗口再播放气泡、声音与动作。普通对话可用 `live2d_pet_status` 核对身体是否可用。

Live2D 可独立运行。Coo 原版对话页需要原版 Desktop Pet 支持读取 Live2D 的消息事件，才能在原版页看到双向记录。原版托盘和两具身体的开关仍由各自的 World 管理。

工作台支持原始 Live2D 模型和符合 Body API 2 的 Coo 形象包，文件夹、ZIP 和拖放走统一导入。两种来源可从模型卡进入同一角色编辑台。形象包可以试播已声明的动作，并按支持项编辑装扮、添加触碰规则。草稿和用户设置按角色单独保存，编辑台可恢复作者默认。

原生设置窗口显示角色封面。模型卡的「编辑」在默认浏览器打开模型编辑页。桌宠的「应用 → 互动设置 → 编辑触碰」直达触碰工作区。桌宠关闭时也能编辑，各模型按来源保留草稿。绘制触碰区会定住模型，可清空本次顶点或草稿中的自定义区。运行详情可隐藏、关闭或恢复穿透。窗口可使用显式配置的 Electron 或本机托管运行时，现有 Electron 缓存可复用。

在「场景 → 壁纸库」导入本机图片、MP4、WebM 或 Wallpaper Engine 项目，也可查找 Steam 已下载的壁纸。使用时保留现有角色和对话。实时项目由 WebWallGL 尝试绘制，加载失败时依次使用项目提供的视频或封面。壁纸的缩放、音量与暂停可以单独控制。「角色构图」按壁纸保存横向站位和接地线，也可从桌宠操作台的场景切换区域调整。抓起角色再松手，角色会落到接地线上。

在「操作台布局」拖动右键操作台预览右边的圆点，点击「保存布局」应用尺寸。组件放进「应用」页会显示为方形入口。

Windows 上可在「显示 → 全屏与直播」开启「截图和录屏时隐藏 Live2D」，并查看 Windows 的应用状态。开关默认关闭。开启后，NVIDIA 即时重放的桌面捕获可能无法启动。OBS 若要单独输出 Live2D，开启「OBS 画面」并复制同页的浏览器源地址。同页可关闭「允许覆盖任务栏」。

## Live2D 运行组件

版本号内的「须知」提供 Core 和 SDK 许可。已有一键安装的本机组件会先校验再复用。首次需要下载时由用户确认许可，Live2D 从官方来源取 Core 和 Web Framework 源码，在本机编译并校验缓存。已经同意过许可时，导入和启动会自动补齐缺失组件。扩展安装包只带获取代码和许可文本，用户模型及运行组件存放在本机。 [Live2D 官方下载页](https://www.live2d.com/en/sdk/download/web/)

## 表现与声音

- Live2D 的一次发言用同一播放时钟协调气泡、动作、语音与口型。声音暂不可用时仍显示文字。
- 「声音」管理 Live2D 的音效、说话声与语音输入。「模型服务」管理语音合成、动作编排和在线转写。
- 本机 GPT-SoVITS 插件可用于 Live2D 语音合成。先在 GSV 开启「开放本机语音接口」并留空令牌，然后在「模型服务 → 添加提供商」选「本机 GPT-SoVITS 插件」。默认地址为 `http://127.0.0.1:9880`。试听后可设为当前语音合成模型，再到「声音 → 说话声设置」启用。音色空白时使用 GSV 当前音色，语速默认 1×。
- 在 Live2D 的麦克风按钮上按住说话，松开发送。取消、隐藏和关闭会释放收音。电脑操作与全局快捷键由原版桌宠管理。
- 四个场景各自保存角色大小。拖动滑杆即时预览，松手保存。桌面使用随身气泡，小屋使用下沿对话区，竖屏显示左右消息，壁纸在下方显示字幕。小屋、竖屏和壁纸直接提供输入和麦克风。

## 开发

运行 `pnpm build`、`pnpm typecheck` 和 `pnpm test`。本地的 `.cortico` 指向目标宿主对应的 Cortico 源码。构建后的面板使用带内容摘要的资源名。通过 Cortico 扩展页面安装本地目录后重启 Core。
